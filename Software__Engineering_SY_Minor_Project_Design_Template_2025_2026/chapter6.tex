\section{Experimental Test Setup}
Testing was conducted across both local development environments and production cloud infrastructure:
\begin{itemize}
    \item \textbf{Local Test Hardware:} Apple MacBook Air (Apple M-series Silicon, 16 GB unified memory, macOS).
    \item \textbf{Production Hosting:} Vercel Serverless Edge Network (Washington, D.C., USA -- East region, Node.js 20.x runtime).
    \item \textbf{AI Inference Infrastructure:} Groq Cloud Language Processing Units (LPUs) accessing \texttt{qwen/qwen3.8-27b} and \texttt{openai/gpt-oss-120b}.
    \item \textbf{Client Devices:} Google Chrome 124 on macOS, Safari on iOS 17, and Firefox 125 on Android.
\end{itemize}

\section{Multi-Ingredient Visual Recognition Validation}
To validate the multi-ingredient recognition capabilities demanded by real-world kitchens, three heterogeneous scenes were rigorously evaluated:
\begin{enumerate}
    \item \textbf{Stocked Refrigerator Shelf:} Contains tightly packed produce and containers. The vision cascade successfully extracted: \textit{Broccoli, Cucumbers, Tomatoes, Green Bell Peppers, Mushrooms, Spinach, Eggs, Butter, Greek Yogurt, Oat Milk, Pickles, Tomato Ketchup, Mustard, Salsa, Orange Juice, Grape Juice} ($16$ items).
    \item \textbf{Rustic Countertop Prep:} An open prep island containing raw produce and cooking essentials. The model identified: \textit{Tomatoes, Onions, Garlic, Green Bell Peppers, Cilantro, Mushrooms, Olive Oil, Salt} ($8$ items).
    \item \textbf{Market Grocery Basket:} Contains raw produce, dry pasta, canned legumes, and hard cheese. The model identified: \textit{Carrots, Lemons, Red Chilies, Rosemary, Garlic, Thyme, Parmigiano Reggiano, Spaghetti, Chickpeas, Olive Oil} ($10$ items).
\end{enumerate}
In all three benchmarks, zero false positives were recorded, and all detected items were automatically populated into the active inventory.

\section{Conclusion}
The \textbf{PlateWise} project successfully demonstrates that advanced multi-modal artificial intelligence, serverless edge computing, and modern frontend frameworks can be harmonized into an elegant, high-impact tool to combat domestic food waste. By automating the visual perception of refrigerator inventories and delivering context-driven, audit-verified recipes, PlateWise eliminates the friction that leads to household food spoilage.

The platform was designed, engineered, tested, and deployed individually by Aadesh Khande as an assignment for \textbf{Continuous Assessment (CA) Activity 2}. The live web application is accessible globally at \url{https://plate-wise.vercel.app}, providing an intuitive, instantaneous, and zero-cost culinary copilot for modern kitchens.

\section{Future Enhancements}
While PlateWise achieves all foundational objectives, future research will explore:
\begin{enumerate}
    \item \textbf{Automated Nutritional Macro Calculation:} Integrating USDA food nutrition databases to calculate exact calorie, protein, fat, and carbohydrate breakdowns per serving.
    \item \textbf{Voice-Guided Hands-Free Cooking:} Implementing Web Speech API speech recognition to allow cooks to progress through steps hands-free while their hands are covered in cooking ingredients.
    \item \textbf{Barcode \& OCR Expiration Date Tracking:} Adding optical character recognition (OCR) to read expiration dates printed on dairy cartons and packaged goods, providing proactive spoilage warning alerts.
\end{enumerate}
